# Lumenfold 开发计划

> 版本 v0.1 · 最后更新 2026-10-07
> 工期假设：**2 名全职工程师**（1 Rust/图像 + 1 前端/插件）。单人开发按 1.6 倍外推。

---

## 1. 技术栈定案

| 层 | 选型 | 理由 |
|---|---|---|
| 外壳 | **Tauri v2**（Rust + 系统 WebView） | 三系统一套 Rust 核心；安装包 ~15MB，冷启动 <1s，常驻内存约 1/5 于 Electron |
| UI | **React 18 + TypeScript + Vite** + TanStack Query/Virtual | 插件作者基数最大，直接决定生态天花板 |
| 样式 | **Tailwind + 独立 token 包** `@lumenfold/tokens` | 插件跟随宿主主题的唯一可靠契约 |
| 图像 | **libvips**（rust-vips）+ libheif + libraw | RAW/HEIC/AVIF/JPEG2000 一条管线；`shrink-on-load` 决定十万张滚动是否流畅 |
| 索引 | **SQLite（WAL）+ FTS5 + sqlite-vec** | 单文件、可备份、零服务、向量检索原生扩展 |
| 推理 | **ONNX Runtime**（Rust `ort`） | Rust 侧最成熟的推理绑定，CPU 多线程调度可控 |
| 插件 | **QuickJS 沙箱**（`rquickjs`）+ 分层 UI | 运行时 ~2MB，可设内存/栈/指令上限，不暴露宿主内存 |

详见 [ADR-0001](./adr/0001-stack-and-license.md)。

| **M7** | 发布 | 3 周 | 20 万张压测、崩溃上报（可选）、自动更新、zh-CN/en、文档与 RFC 流程、插件市场（GitHub 注册表 + 签名清单）、v1.0 | 三系统商店包签名与公证通过 |

**合计 25 周（约 6 个月，双人）。**

### 取舍顺序

```
M1 → M2 → M3  （没有它产品不成立，必须做）
M4 → M6        （差异化，可按资源插入）
M5             （第一个可砍项：模型效果最不可控）
```

若工期被压缩：**砍 M5 人脸，不要砍 M2 写回**。元数据写回的正确性是用户信任的基础，出一次数据损坏事件就再也拉不回来。

## 3. 性能预算

写进 CI 基准，超标即失败。

| 指标 | 目标 |
|---|---|
| 10 万张首次扫描建库 | < 10 min |
| JPEG 缩略图生成 | > 200 张/s/核（降采样路径） |
| 1000 格视口首屏出图 | < 100 ms |
| 语义检索 P95 | < 200 ms |
| 常驻内存（10 万张库） | < 300 MB |
| 冷启动到可交互（10 万张） | < 6 s |

## 4. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **三平台原生依赖地狱**（libvips / libheif / libraw 构建） | 阻塞发版 | 私有仓库存预编译二进制 + 校验和，CI 固定版本；同时维护无原生依赖的"便携版"降级路径 |
| **签名与公证**（Apple/Windows 证书、年费、CI 密钥管理） | 阻塞分发 | M0 即采购并配置 CI 签名，密钥入 secrets 库；无签名包不允许对外发布 |
| **人脸模型许可** | 管理不当导致的分发与合规风险 | **不内置权重** + 安装后按需下载 + 下载前明示许可 + SHA-256 校验 + 授权记录。InsightFace 系权重为非商用许可，走用户自备通道，宿主不提供下载入口。详见 [ADR-0002](./adr/0002-model-distribution-and-licensing.md) |
| **模型体积**（CLIP int8 ~350MB） | 首次体验劣化 | 不进安装包；改为按需后台可续传下载 + 本地模型注册表。方案见 [ADR-0002](./adr/0002-model-distribution-and-licensing.md) |
| **插件 API 破坏性变更** | 生态流失 | `apiVersion` + RFC 流程 + 至少两个小版本迁移垫片 + SDK 独立发版 |
| **缓存膨胀** | 吃满用户磁盘 | 内容寻址 + LRU 上限（默认 10GB，可配）+ 一键重建工具 |
| **大库数据库损坏** | 数据不可恢复 | WAL + 迁移前自动备份 + 定期 `integrity_check` + 自动回滚到最近备份 |
| **离线逆地理编码** | 地图体验降级 | 以 GPS 坐标为准；逆地理仅在联网时惰性查询并缓存。无图源时地图面板降级为坐标列表 |
| **范围过载** | 做不完 | 见 §2 取舍顺序；M5 为第一砍项 |

## 5. 立刻开工（M0 第一周，无需额外决策）

1. 初始化 workspace：`cargo new lumenfold-core` + 三系统 GitHub Actions（Windows/MSVC、macOS universal、Linux musl）
2. 定稿 `assets` 表 DDL 与迁移框架，跑通「扫描 1 万张 → 建库 → CLI 查询」
3. 同步启动 **RFC-0001（插件 API 草案）**，这是唯一必须"一次想清楚"的东西。晚一周动笔，所有早期插件都会长成错的形状。
